# Web Design and Development Coursework

## Overview

Group coursework for the University of Westminster focused on designing and developing a multi-page website using HTML, CSS and JavaScript. The project involved collaborating as a team to create a consistent website design, implement interactive features and deliver a connected user experience.

## Website Features

* Multiple interconnected pages with a consistent layout and navigation.
* Content pages presenting information about the chosen website topic.
* Interactive features to improve navigation and usability.
* Individual page editor pages documenting each team member's role and contributions.
* Responsive styling and accessibility considerations.

## Development and Collaboration

The project involved dividing responsibilities across a four-person team, coordinating page development and following shared requirements for website structure, styling and navigation. Version control was used to support collaboration and track changes.

## Technologies

* HTML
* CSS
* JavaScript
* Git and GitHub

## Skills Demonstrated

* Web design and front-end development
* User interface and navigation design
* JavaScript interactivity
* Teamwork and version control
* Accessibility and website validation
